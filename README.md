# Template de Relatório — ILUM

Template em LaTeX para elaboração de relatórios acadêmicos da **ILUM — Escola de Ciência**, vinculada ao **CNPEM**.

## Disclaimer ⚠️
Este projeto é independente e não possui vínculo oficial com o Centro Nacional de Pesquisa em Energia e Materiais (CNPEM) ou com a ILUM - Escola de Ciência. 

O template foi desenvolvido de forma independente e não representa, não é mantido e não é endossado pelo CNPEM ou pela ILUM.

O uso dos nomes, logotipos ou referências às instituições neste projeto não implica qualquer relação oficial, aprovação ou afiliação institucional. Além disso, as informações exemplo contidas no arquivo <dados.tex> são públicas e podem ser obtidas com uma pesquisa em qualquer search engine.


## Como usar

1. Clone ou faça o download deste repositório.

2. Edite o arquivo `dados.tex` com as informações do seu relatório.

3. Insira o rodapé e o cabeçalho na pasta "internals/template/figs", com os nomes <cabeçalho.png> e <rodapé.png> (pegue na intranet ou peça a algum colega)

3. Compile o arquivo `main.tex` com um compilador LaTeX (o padrão é o XeLaTeX).
